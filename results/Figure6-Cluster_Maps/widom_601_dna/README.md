# Clustering PDBs

Provided in this folder are representative PDB structures for the predominant H4-H3 histone connector conformations from each DNA unwrapped stage, as seen in the Cluster Map of Figure 6.

As the PDBs included contain all the protein and nucleic residues, for accessibility below are the numbered residues for either the H4-H3.1 or H4-H3.2 histone that was used to represent each cluster via DBSCAN calculations.

Cluster 0,2,3 - H4: residue 704-776; Connector: residue 777-798; H3: residue 799-890

Cluster 1,4,5,8 - H4: residue 305-377; Connector: residue 338-399; H3: residue 305-491
